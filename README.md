## Overview

Veteris Helper is a small companion package for Veteris.

Most users do not need to install it manually. It is installed with Veteris from
my repo.

## Installation

Add `https://repo.victorlobe.me` to Cydia and install **Veteris**.

The project website is available at `https://veteris.victorlobe.me`.

## Requirements

- Jailbroken iPhone, iPad, or iPod touch
- iOS 5.0 or newer
